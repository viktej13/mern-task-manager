# MERN Task Manager

A full stack MERN Task Manager application built using:

- MongoDB
- Express.js
- React.js
- Node.js

## Features

- User Registration
- User Login
- JWT Authentication
- Create Tasks
- Delete Tasks
- Protected Routes

## Tech Stack

Frontend:
- React
- Axios
- React Router DOM

Backend:
- Node.js
- Express.js
- MongoDB
- JWT

## Run Project

Backend:

npm install
npm run dev

Frontend:

npm install
npm start
